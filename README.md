# Security Wordlist & Password Utilities

Набор Python-скриптов для генерации, комбинирования и трансформации словарей, а также для детерминированной генерации паролей. Инструменты полезны при проведении тестов на проникновение (Pentesting) и изучении безопасности веб-приложений.

## Состав инструментов

### 1. `combine_str_pref.py`
Скрипт для комбинирования строк из двух файлов или кодирования списка в Base64.

* **Объединение:** Берет строки из двух файлов и соединяет их через указанный символ (например, для создания пар `user:pass`).
* **Кодирование:** Если передан один файл, кодирует каждую строку в Base64.

**Использование:**
```bash
# Объединение двух списков
python3 combine_str_pref.py users.txt passwords.txt ":"

# Кодирование списка в Base64
python3 combine_str_pref.py raw_payloads.txt
```

---

### 2. `combine_str_list.py`
Инструмент для подготовки списков к атакам на аутентификацию, где бэкенд принимает массив данных (например, JSON-списки). Позволяет оборачивать пароли в кавычки и добавлять префиксы/постфиксы.

**Использование:**
```bash
python3 combine_str_list.py '{"passwords": [' ']}' 10 passwords.txt
```
*Где `10` — периодичность повторения структуры.*

---

### 3. `gen_from_hash.py`
Детерминированный генератор паролей. Позволяет генерировать уникальные сложные пароли для разных ресурсов, используя один мастер-секрет.

* **Метод 1:** Генерация на основе SHA256 хеша.
* **Метод 2 (HMAC):** Производная пароля на основе мастер-секрета и доменного имени.

**Использование:**
Запустите скрипт и следуйте инструкциям ввода:
```bash
python3 gen_from_hash.py
```

## Требования
* Python 3.x
* Стандартные библиотеки (`hashlib`, `base64`, `hmac`, `random`).
